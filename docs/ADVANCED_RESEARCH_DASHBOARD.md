# Sentum Advanced Research Dashboard

Phase 14 turns the local read-only dashboard into a research workbench backed by the Phase-13 experiment registry and immutable run artifacts.

## Start

```bash
./sentum dashboard
```

The legacy flag form remains supported:

```bash
./sentum --dashboard
```

Open:

```text
http://127.0.0.1:8080
```

The server remains loopback-only and exposes GET endpoints only.

## Research Lab

The Research Lab provides:

- experiment history from `log/experiments.sqlite3`
- primary-run selection and second-run comparison
- Validation vs final Holdout metrics
- deterministic Holdout equity and drawdown curves
- parameter heatmap using `lookback x entry_threshold`
- Deflated Sharpe, parameter stability and overfit-gap visibility
- Bootstrap net-profit confidence interval
- Monte-Carlo net-profit and drawdown intervals
- Monte-Carlo probability of loss
- Holdout regime performance
- Git/config/risk/dataset provenance
- single-asset and portfolio-run comparison metrics

## Research visualization artifact

New Phase-14 single-asset experiments create:

```text
research-visualization.json
```

inside their versioned experiment directory. The artifact is generated by deterministically replaying the already-selected final Holdout parameters through the normal `ReplayClock`, `TradeEngine`, `RiskManager` and simulated execution stack.

This avoids drawing an artificial equity curve from aggregate metrics. The artifact contains actual completed Holdout trade equity and drawdown paths.

Older experiment runs remain visible. They simply display `No curve artifact available` because they predate Phase 14.

## Read-only API

Existing endpoints remain available. Phase 14 adds:

```text
GET /api/experiments?limit=200
GET /api/experiment?run_id=<run-id>
GET /api/experiment/trials?run_id=<run-id>&limit=10000
```

`/api/experiment` resolves the output directory through the SQLite experiment registry. Browser input is never interpreted as a filesystem path.

The detail endpoint combines:

- registry metadata
- datasets and SHA-256 hashes
- artifact hashes
- `research.json`
- `research-visualization.json`
- `portfolio-research.json`

when those artifacts exist.

## Parameter landscape

The current heatmap uses:

```text
X = lookback
Y = entry_threshold
cell = best validation score among trials sharing X/Y
```

Other risk/execution dimensions remain represented in the underlying full trial table and can be expanded into configurable heatmap axes in a future dashboard iteration.

## Security boundary

The dashboard still exposes no endpoint for:

- placing or cancelling orders
- changing strategy/risk configuration
- resetting the kill switch
- enabling Testnet or production trading
- reading credentials
- modifying experiment artifacts

Research visualization is deliberately separated from execution control.
